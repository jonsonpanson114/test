# デザイン部品と各ページのレシピ

目次: 1. 配色・書体 / 2. 部品 / 3. ページ別レシピ / 4. パターン集（事例を増やす）/ 5. 別テイスト5種 / 6. はまりやすい点

## 1. 配色・書体
| 用途 | 値 |
|---|---|
| 背景（紙） | `#F4EFE4`（クリーム）＋ドット `radial-gradient(rgba(35,41,43,.13) 2px, …)` 34px |
| 文字 | `#23292B`（本文の補足は `#586064`） |
| 製品色 `--accent` | 製品の実物の色から1色（IDOは写真のティール `#2F5D62`） |
| 付箋 | 黄 `#F6E27A`／橙 `#F5B25A`／青 `#7DBBE0`／桃 `#F3B3B0`／緑 `#C5DDAE`（フライヤーの付箋・窓の色から） |

書体（`scripts/setup_fonts.sh` で取得）: `ZMG`=Zen Maru Gothic（見出し900・小見出し700）／`HAND`=Zen Kurenaido（補足・ラベル・数字の脇）／`OUT`=Outfit（英字・数字）／`NJP`=Noto Sans JP（雑誌風など落ち着いた版）。
見出しは大きく太く（54〜120px）、補足は手書き風で20〜28px。注記は17px以上（小さすぎるとPDFで潰れる）。

## 2. 部品（`assets/template.html` にCSSあり）
| クラス | 役割 | 使いどころ |
|---|---|---|
| `.stk` | 付箋（上にマスキングテープ） | 課題・用途・ステップ・コンセプトの文 |
| `.pol` | ポラロイド（写真＋手書きキャプション） | 製品写真・CG。**キャプションに「写真」「CG」と書く** |
| `.strip` | ちぎった紙 | 写真や付箋の壁の上に載せる見出し・まとめの一文 |
| `.stamp` | 破線の丸いスタンプ | 主要な数字（4人用／5.61㎡／24.2dB※） |
| `.tagc` | 穴あきの紙タグ | 選べる仕様の選択肢（ドア・パネル・クロス） |
| `.lb` ＋ SVGの曲線矢印 | 手描き風ラベル | 写真への書き込み（下記） |
| `.mark` | 蛍光ペン | 1ページに1か所だけ、いちばん言いたい語句 |
| `.sol`（`#s2`内） | 同色の丸いシール | 課題に対する「〇〇なら」の答え |

**傾け方**: `--r` を `-2deg〜3deg` で、隣どうしで符号を変える。0度の要素は本文・数値の帯だけ。
**影**: `0 14px 20px -12px rgba(0,0,0,.45)` が紙っぽい。濃くしない。

### 写真への書き込み（手描き風の矢印）
全面SVG（`position:absolute; inset:0`）に `<path d="M x1 y1 Q cx cy x2 y2" marker-end="url(#ah)">` を引く。ラベルは写真の両脇に縦に並べ、矢印は写真内の対象まで。
- 写真に `rotate` をかけるなら、矢印の座標は**回転しない前提で計算**し、傾きは1〜1.5度までにとどめる（ずれが数pxで済む）。
- 写真内の位置は「写真左上＋幅×割合」で計算する（実測は一度ラフに描いてから微調整）。

## 3. ページ別レシピ
- **表紙**: 背景＝付箋の壁の写真（なければ付箋色のグラデ）＋半透明の白をかぶせる。左に製品ロゴを白いカード（−2度）、右上にピンクの付箋で呼びかけ（"I do. Come with me?" 等）、下にちぎった帯でコピー、右にポラロイド、スタンプ3つ。
- **課題→解決**: 左に付箋2×2、中央に手描き矢印と「〇〇なら！」、右に写真、写真の下に同色のシール4つ。まとめの一文は一番下に大きく1行。
- **コンセプト**: 見出しを120px級にして、右半分に「I DO ＿＿」＋用途の付箋を散らす。意味が2つあるなら2枚の付箋に（由来を示すアイコンを自作で添えてもよい）。
- **設備（写真に書き込み）**: 写真を中央、ラベルを左右に、細い写真2枚をポラロイドで右下に。
- **仕様選択**: 上段に事例写真3枚＋色分けの線画（部位名に矢印）、下段に紙タグ4枚。
- **音・安全（濃い背景）**: 背景 `#1D393D`。特大の数字（270px級）、音が広がる同心円と測定点の模式図、法規・認証は白い丸のシール。注記は薄い色で必ず残す。
- **サイズ**: 方眼紙背景（`linear-gradient` 40px）、平面図と正面図は線画（寸法線はオレンジ）、数値は白い帯、チェックリストは罫線ノート（赤い縦線、オレンジのチェック）。
- **クロージング**: 表紙と同じ付箋の壁。3ステップの付箋、青緑の帯でCTA（連絡先は空欄プレースホルダ）、ピンクの付箋で呼びかけを繰り返す、最後にちぎった帯で締めのコピー。

## 4. パターン集（事例を増やす）
「いろんなパターンを見たい」は、**写真を増やすのではなく、選べる仕様の組み合わせを描き起こす**依頼だった。
1. 仕様書から「どの面・部位で何が選べるか」と**制約**（固定の面、片方しか選べない組み合わせ、取付位置の制限）を表にする。
2. 制約の範囲だけで組み合わせを作る。名前・使い方の説明は、資料に書いてある特長（開放的／吸音が追加される／省スペース 等）だけから付ける。
3. 1枚に3パターン（カード3枚、傾けて並べる）。各カード: パターン番号、名前、一言、**正面図＋平面図**、仕様チップ4つ、おすすめの使い方。
4. 正面図・平面図・色違いは **JSで生成**する（`assets/pattern_generator.js` が実例）。手で8個描かない。色の組み合わせは「カラー例（イメージ）」と明記。
5. 最後に、資料にある実際の写真・CGをポラロイドのギャラリーにする（写真かCGかを書く）。
組み合わせ数を言うなら「以上」を付け、前提（例: 側面を同一仕様とした場合）を添える。

## 5. 別テイスト5種（方向性を見比べたいときの早見）
| 記号 | 雰囲気 | 要点 |
|---|---|---|
| A 雑誌風 | 写真全面＋細い大きな英字＋罫線 | `NJP` 300、余白、写真は全面。冷たくなりやすい |
| B ポップ | 製品の窓色を前面、丸ゴシック900、白いカードに影 | 親しみ◎、商談では軽く見えることも |
| C ダーク | 暗い背景、アーチ型の写真、オレンジのアクセント | 高級感◎、相談しにくい印象になりがち |
| D 青焼き図面 | 青地に白線、写真は青のモノトーン（`mix-blend-mode:screen`） | 設計者・施工者向け。数値が主役 |
| E ベント | 角丸タイルに写真・数字・ロゴを敷き詰め | SNS・バナー・スマホ向け |
結論: このプロジェクトで選ばれたのは付箋（この資料のスタイル）。親しみと情報量のバランスが取れる。

## 6. はまりやすい点（実際に踏んだもの）
- **白背景のロゴ画像**は、明るい面では `mix-blend-mode:multiply`、暗い面では `filter:invert(1); mix-blend-mode:screen` で背景を消す。
- `clip-path` のちぎり帯は、中の文字が端で欠ける。左右の余白（padding 40px以上）を取る。
- 日本語は幅が読みにくい。1行で収めたい見出しは `white-space:nowrap` にして、**幅を実測して**フォントサイズを決める（レンダリングで確認）。
- 傾けた要素・円形スタンプは、隣の要素と重なりやすい（帯の文字が隠れるなど）。重ねるときは、文字の位置を最優先で空ける。
- `pdfimages` で出る画像には、ソフトマスクや小さなアイコンが混ざる。コンタクトシートで見て選ぶ。白背景のイラストは、白い角丸カードに載せるときれい。
- Googleフォントは、`User-Agent: curl` でCSSを取るとTTFのURLが返る（`scripts/setup_fonts.sh`）。ブラウザのUAだとwoff2のunicode-range分割になる。
- 実行環境にplaywrightが無いときは `npm i -g playwright` ではなく、既存のChromiumを `executablePath` で指定する（環境のドキュメントに従う）。
