# 内容のルールと、渡すときの確認リスト

目次: 1. 表現 / 2. 数値 / 3. 資料に無いことを書くとき / 4. 公開前の確認リスト

## 1. 表現
| 避ける | こう書く |
|---|---|
| 完全防音／会話が聞こえない | 周囲に配慮した遮音性能。測定条件つきで数値を示す |
| 消防設備は不要 | 〜の要件を満たす仕様。設置時は各自治体の消防署への申請が必要。条件は物件ごとに確認 |
| 〜を保証／必ず | 〜に配慮した仕様／〜に対応 |
| 4〜6人（資料により揺れる） | PR資料では製品名と整合する「4人用」を基本にする。最大人数に触れるかは確認事項にする |
| 「社内資料」「勉強会資料」 | お客様向けの文面には出さない（「選べる仕様」「イメージ」等に言い換える） |

## 2. 数値
- 資料の数値をそのまま使う。丸め直さない（24.2dB → 24dB にしない。フライヤーが丸めていても、条件つきの正確な値を優先）。
- 測定値には、**周波数・測定条件・参考値である旨**を同じページに（例: 「500Hz／室内側約90dB／ブースから1m離れた3地点／実設置環境での参考値」）。
- 寸法は外形／芯々／室内の別を取り違えない（外形 W2,430、芯々 W2,380 など）。変更不可なら「寸法変更には対応していません」も残す。
- 組み合わせ数は「16通り以上」のように下限で言い、前提を添える。

## 3. 資料に無いことを書くとき
次の3種類は、ページ上は自然に書いてよいが、**最後に「資料に無い案」として一覧で報告する**。
1. 自分で付けた名前（パターン名など）と、使い方の提案
2. 自分で計算した値（面積の畳換算など。換算式を注記に入れる）
3. 色の例（実際に選べる塗装色・品番とは別物。「カラー例（イメージ）」と明記）
自作した図（正面図・平面図）は「イメージ図」。社内資料の図面とは寸法が一致しないと伝える。

## 4. 公開前の確認リスト（当てはまるものを渡す）
- [ ] 元資料が【社外秘】なら、写真・CG・図・数値を社外向けに使ってよいか（出どころの部署に）
- [ ] 法規まわりの言い回し（「免除の対象となる」「要申請」等）が、法務・製品企画の見解と合っているか
- [ ] 遮音値などの注記（周波数・条件・参考値）が、社内の表記ルールと合っているか
- [ ] 人数の表記（4人用／最大6人）の扱い
- [ ] 資料に無い案（パターン名・用途・換算値・色の例）を使ってよいか
- [ ] 問い合わせ欄（部署・担当者・連絡先）の記入
- [ ] 品名・色名の表記が正式名称と一致しているか

## 5. 渡し方のトーン（ユーザー設定が「率直な相棒」のとき）
- 良い点と弱い点を分けて言う。「ここは遊びが強すぎて、役員向けには砕けすぎるかも」のように、**その資料の弱点も自分から言う**。
- 迷う選択（別テイストにするか、中身を増やすか等）は、推奨を1つ示して理由を添える。
- 最後に「次の一手」（誰に見せて何を確認するか）を1つ書く。
