# 雰囲気メモの書き方

資料の見た目は、読み手に「これは自分たちのための資料だ」と感じさせる最初の手がかり。
その雰囲気は、渡された資料の中にすでにある。**探して、言葉にして、そこから設計する。**

## 1. 何を見るか（資料の画像を実際に開いて）
| 見るもの | 読み取ること |
|---|---|
| 表紙・フライヤー | 全体の温度（堅い／親しみ／静か／賑やか）、余白の量、モチーフ（IDOなら付箋） |
| 色 | 使われている色の数と彩度。製品そのものの色（実物写真の色）は、必ず軸の1色に |
| 書体 | 細い・太い、明朝・ゴシック、英字ラベルの有無、字間 |
| 写真 | 実物の写真かCGか、引きか寄りか、人が写るか。写真の主役感の強さ |
| 図面・図表 | 線の太さ、寸法線の有無、どれくらい専門的か |
| コピーの口調 | 話しかけるか、説明するか。短いか長いか |
| 読み手 | 設計者（図面と数値が欲しい）／施主（空間のイメージが欲しい）／現場担当（使い方が知りたい） |

## 2. 雰囲気メモ（この形で書き、ユーザーに見せる）
```
【雰囲気メモ】
キーワード： （3語。例：気軽・手づくり・明るい ／ 静か・建築的・精密）
色：         軸＝（製品の実物の色）、補助＝（資料から拾った色 2〜3）
書体の印象：  （例：丸くて太い見出し＋手書きの補足 ／ 細い明朝の見出し＋英字の小さなラベル）
コピーの口調： （例：話しかける ／ 淡々と判断材料を示す）
写真の扱い：  （例：傾けて貼る ／ 全面で見せる ／ 枠に入れて余白を取る）
避けること：  （例：均等なカードの羅列、派手な色数、他製品の写真の代用）
読み手：     （誰が、どんな場面で見るか）
```
メモのあとに、表紙1枚＋中身1枚を作って見せる。「この方向で全ページ作ってよいか」を聞く。

## 3. 例（雰囲気の答えは製品ごとに違う）
| 製品・資料 | 手がかり | 出てきた雰囲気 |
|---|---|---|
| IDO（4人用ワークブース） | フライヤーの表紙が付箋の壁、「I do. Come with me?」、窓がオレンジ・イエロー・ブルー | 付箋・ポラロイド・ちぎった紙・手書き風。話しかける口調。→ この見た目が `assets/template.html` と `references/design-system.md` |
| 可動間仕切（設計者向けの提案資料） | 建築カタログ、実施工写真が主役、図面・断面図、英字の小さなラベル | **IDOと同じにしない。** 静か・建築的・写真主導の雰囲気になるはず。実際の資料を見て決める（付箋は当てはめない） |

IDOの回答は、そのままコピーしない。部品の作り方（傾き・影・枠・自動採番・写真枠）だけ流用できる。

## 4. 方向が決まらないとき
同じ内容の表紙を、2〜3方向で作って見比べてもらう。方向の候補は、雰囲気メモのキーワードから作る（例：手づくり／雑誌風／濃い背景で写真を際立たせる／青焼き図面風／写真を敷き詰めるタイル）。
**見比べてもらうのは「雰囲気の方向」であって、「中身を増やす」依頼とは別。** 迷ったら最初に聞く。
