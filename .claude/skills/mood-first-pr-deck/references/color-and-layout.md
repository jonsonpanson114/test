# 色とレイアウトの基本（情報量の多い資料向け）

77ページのような情報量の多い資料で、色を5〜6色使って「ごちゃごちゃで見にくい」と言われた経験から。
調べた一般則と、それを今回どう使ったか。

## 色は3色まで（70：25：5）
- ベース70%＝白。メイン25%＝ブランドの色1つ。アクセント5%＝「ここを見て」の場所だけ（暖色が目に入りやすい）。
- 章ごとに色を変えたくなるが、**色数が増えるだけで見にくくなる**。章の区別は、色ではなく**大きな番号と位置**で。
- 色の意味を固定する。例：赤＝番号・強調語、青＝見出しの帯・表の頭・グラフ。この2色以外（青緑・橙・桃・えんじ）は使わない。
- 地味な灰色（`#F3F2EF`、罫線 `#d9d6d1`）は色数に数えず、区切りと強調の背景に使ってよい。

## 箱を減らして、線と余白で区切る
- 太い枠＋影のカードを並べると、情報が増えるほどうるさくなる。**細い罫線（2px）と余白**で区切る。
- 余白はスライド面積の15〜20%以上。詰め込むより、ページを分ける。
- 番号は、大きく・赤で・本文より先に目に入れる（階層：タイトル → 番号 → 小見出し → 本文）。

## ページごとに構図を変える（ただし部品は共通）
- 全面写真＋右に文章（製品ページ）／大きな写真1＋小4（場面）／5列の番号（メリット）／2列比較（TLDとD値）／表（数値）／章扉（大きなアーチと番号）。
- 同じ型の繰り返しは「テンプレート感」になる。型は4〜5種類まで、順番にローテーション。
- 写真に文字を重ねるなら半透明の暗幕を敷く。写真が主役のページには、文字を置かない。

## 自動拡大は慎重に
- ページごとに本文を拡大して余白を埋める方法は、折り返しが増えて破綻しやすかった。**最初から余白ありの設計**にして、拡大に頼らない。

出典（一般則）：配色の70:25:5、色は3色に絞る、アクセントは1スライド1か所、余白15〜20%、グリッドと整列。
